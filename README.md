# WLSA Store

Standalone frontend for `https://wlsa-store.vercel.app`.

The site is intentionally static. Product browsing, category filters, product drawers, image zoom, search, and the local shopping bag run in the browser. Checkout remains ready for the separate store backend to connect later.

## Local preview

```bash
python3 -m http.server 3000
```

Open `http://127.0.0.1:3000/`.
